# 暗色紧凑界面与 Windows 图标设计规格

## 目标

在不删除、不隐藏现有第一版与第二版功能的前提下，将 PySide6 主界面重排为规划书高保真稿的紧凑双栏结构，并修复源码启动与文件夹版 EXE 在 Windows 任务栏显示默认图标的问题。

设计依据：

- `D:\code\codex\shadowing\兒童影子跟讀播放器規劃書.html` 第四章家长模式高保真稿。
- 用户提供的界面截图。
- 当前 `MainWindow` 已有的按钮、组合框、快捷键、转写、复习和句子编辑行为。

## 方案选择

评估过三种方案：

1. 只替换颜色与圆角：改动小，但不能解决两排控制项横向堆叠造成的臃肿。
2. 完全照搬高保真稿：视觉最接近，但会遗漏第二版已有的字幕来源、合并、拆分、复习、循环次数与自动前进等入口。
3. 结构对齐并扩展高保真稿：采用。保留稿件的顶部状态、左侧影片、右侧句子、底部主控制条，同时把已有低频功能放入对应区域。

## 信息架构

### 顶部栏

- 左侧保留“打开视频”。
- 中部显示当前文件名；未打开时显示就绪提示。
- 右侧保留字幕来源与“英文 / 双语 / 隐藏”显示选择。
- 顶部栏高度固定、内容单行，减少无效留白。

### 主内容双栏

- 左栏约占 64%，包含原生 mpv 影片窗口、大字字幕、中文翻译、跟读提示和一句一格进度条。
- 右栏约占 36%，包含“句子清单”标题、收藏提示、句子表格，以及合并、拆分、复习三个现有功能。
- 合并、拆分属于句子编辑操作，放在句子清单标题栏；复习清单放在右栏底部。按钮始终可见，不放入溢出菜单。
- 句子表格保留星号勾选列、双语内容、扩展选择和点击跳播。

### 底部控制区

- 第一组为上一句、重播本句、播放/暂停、下一句四个主按钮。
- 播放/暂停使用更强的实心强调样式，其他三个使用描边方形按钮。
- 后续依次保留模式、每句次数、速度、留白倍数、循环次数与自动前进。
- 参数控件改为紧凑胶囊/小型组合框，不改变其 `currentData()`、信号或快捷键行为。
- 最下方保留状态文字，持续承载转写、恢复进度、错误与收藏提示。

## 暗色视觉系统

从规划书的蓝色、蜂蜜金、苔绿色语义映射到低眩光暗色界面：

- 应用背景：`#101419`
- 主表面：`#151B21`
- 次级表面：`#1B232B`
- 悬浮/选中表面：`#203D57`
- 边框：`#2B3540`
- 主文字：`#EDF3F7`
- 次文字：`#9AA7B2`
- 蓝色强调：`#66A8E4`
- 收藏金色：`#E6A84C`

界面不使用渐变。圆角集中在 8–12 px，控件最小高度 34 px，主要播放按钮 46 px。字体使用 `"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`。表格行高根据单语/双语内容自适应，选中行使用深蓝底而非高亮白底。

## 代码边界

- 新增 `ui/theme.py`：只保存主题色、全局 QSS 与局部控件样式辅助函数。
- 修改 `ui/main_window.py`：重排现有控件，不改变业务方法、公开属性名或信号连接。
- 修改 `ui/sentence_progress_bar.py`：使用主题色绘制更薄、更清晰的分段条。
- 新增 `runtime/app_identity.py`：解析图标路径、设置 Windows AppUserModelID、把图标应用到 QApplication。
- 修改 `app.py`：创建窗口前配置应用身份与全局图标。
- 修改 `packaging/ShadowingPlayer.spec`：将 `assets/app-icon.ico` 放入 `_internal/assets`，确保运行时可读取。

## Windows 图标根因与修复

当前 PyInstaller 只通过 `EXE(icon=...)` 写入可执行文件资源。这能影响资源管理器中的 EXE 图标，但应用没有：

- 调用 `QApplication.setWindowIcon()`；
- 为窗口提供运行时 `QIcon`；
- 设置稳定的 Windows `AppUserModelID`。

因此 Windows 任务栏可能使用 Qt/默认进程图标或错误分组图标。修复流程：

1. 在创建 QApplication 前调用 `SetCurrentProcessExplicitAppUserModelID("ShadowingPlayer.Desktop")`。
2. 创建 QApplication 后从源码 `assets/app-icon.ico` 或冻结包 `_internal/assets/app-icon.ico` 加载 QIcon。
3. 设置 QApplication 全局图标；主窗口继承并显式接收同一图标。
4. PyInstaller 同时保留 EXE 资源图标并打包运行时 ICO。

## 兼容与验证

- 不改变现有快捷键、模式枚举、设置格式、数据库结构或播放状态机。
- 现有测试中通过属性访问的按钮和组合框名称保持不变。
- 新增测试验证所有既有控件仍存在于可见布局、主题已应用、窗口尺寸和分栏比例合理。
- 新增纯函数测试验证源码/冻结模式图标路径，以及 Windows AppUserModelID 调用。
- 使用假播放器启动真实 Qt 窗口并截屏，检查 1180×720 与较小窗口下没有底部控件被裁切。
- 完整测试通过后重新构建文件夹版，运行 `ShadowingPlayer.exe --smoke-test`，再检查 EXE 图标资源与运行时 ICO 均存在。

## 明确不做

- 不实现规划书第三版的录音、孩童模式、星星目标或统计。
- 不新增设置页。
- 不更改字幕、转写、收藏、复习、合并/拆分、进度记忆的业务行为。
- 不把低频功能藏进菜单或删除按钮。

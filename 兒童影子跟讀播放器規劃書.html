第一章

專案概述與設計原則

家長載入卡通影片後，軟體自動把語音切成句子清單，支援逐句播放、自動留白等孩子模仿、單句循環、降速影子跟讀與錄音對比。整份規劃圍繞兩條核心原則：

1. 一切控制以「句子」為最小單位，而非秒數。 傳統播放器的 AB 循環要手動設點，操作成本太高。句子邊界最可靠的來源是字幕時間軸，因此軟體骨架是：影片 → 帶時間戳的句子清單 → 所有操作（上一句、重播、循環、留白）都針對句子。

2. 雙介面。 家長模式功能齊全；孩童模式只保留三顆大按鈕與獎勵系統，並鎖定防止誤觸退出。

第二章

語句自動切割

2.1 三層策略（依優先順序）

層級做法
① 字幕優先MKV 常內嵌字幕軌（以 ffmpeg 抽取：ffmpeg -i in.mkv -map 0:s:0 out.srt）；MP4 搭配同資料夾同名 .srt / .ass 自動載入。字幕每一條自帶起訖時間，直接解析為句子清單——零成本、最準確。
② 本機 AI 轉寫無字幕時用 faster-whisper（small 模型、int8 量化，CPU 即可）離線產出帶時間戳的句子，存成 .srt 快取。20 分鐘卡通約 3–5 分鐘完成，背景執行並顯示進度；之後再開同一部片即秒載入。
③ 切割微調相鄰過短句（< 1 秒）自動併入下一句；過長句（> 8 秒）在停頓處拆分；每句起訖各外擴 0.2–0.3 秒緩衝避免切字；家長可在句子清單手動「合併 / 拆分」。

2.2 句子資料欄位

index（句序）、start / end（起訖毫秒）、text_en（原文）、text_zh（中文，選配）、practiced（已練習）、starred（收藏）。

第三章

播放模式

模式行為適用情境
觀看模式正常連續播放，字幕高亮跟隨先熟悉劇情
逐句跟讀（主力）播完一句 → 自動暫停留白 → 自動播下一句日常練習
單句精聽鎖定當前句循環 N 次或無限循環攻克難句
影子跟讀連續播放但整體降速 0.6–0.9×程度提升後同步開口

逐句跟讀的關鍵細節：留白時長＝該句長度 × 倍數（預設 1.5，可調 1.2–2.5），固定秒數對長短句都不合適；可設定每句先連播 1–3 次再留白；前進方式可選「倒數結束自動下一句」或「手動確認」；留白期間顯示「換你說！」提示與倒數圈。

錄音對比（強烈建議做）：留白期間自動錄下孩子的聲音，之後播放「原音 → 孩子的聲音」對比。六歲兒童通常非常喜歡聽自己的聲音，這是最有效的參與誘因。刻意不做 AI 發音評分——語音辨識對兒童發音準確率不穩，錯誤的低分只會打擊信心；「聽自己 vs 原音」能讓孩子自然自我修正。

變速不變調（必做）：所有變速皆須 time-stretch 處理（mpv 內建 scaletempo2 濾鏡），否則慢速變低沉怪聲、快速變花栗鼠音，孩子會抗拒。

6.2 沙發遙控

無線簡報筆或迷你數字鍵盤（百元等級）本質是發送鍵盤訊號，搭配自訂鍵位映射即可在沙發距離遙控，零額外開發。

6.3 記憶與複習

每部影片自動記憶播放位置、速度、模式、字幕設定。收藏句可跨影片彙整成「複習清單」，一鍵連續播放多集裡的難句，同樣支援逐句留白跟讀。

6.4 護眼提醒

連續使用達設定時長（預設 20 分鐘）時，孩童模式顯示休息提示動畫。

第七章

技術選型（Windows 11）

7.1 主方案

元件選型理由
介面框架Python + PySide6（Qt）桌面介面成熟、打包容易
播放核心libmpv（python-mpv）MKV/MP4 與內嵌字幕全格式支援；scaletempo2 變速不變調；毫秒級精準 seek（hr-seek）
語音轉寫faster-whisper（small，int8）本機離線、免費，CPU 可跑
錄音sounddevice（16 kHz 單聲道）輕量穩定
資料儲存SQLite + settings.json進度 / 收藏 / 統計

全程離線運作，無隱私疑慮。

7.2 替代方案

Electron 或 Tauri 做介面（孩童模式的動畫用 CSS 容易做），但瀏覽器 <video> 對 MKV 支援差、變速常變調，播放核心仍應掛 mpv；打包體積也較大。

7.3 為何不用現成軟體

PotPlayer 有 AB 循環但沒有「句子」概念；Language Reactor 僅限瀏覽器串流。沒有現成品同時具備「本機 MKV + 逐句自動留白 + 兒童介面 + 錄音對比」，這正是自製的價值。

第八章

開發分期

第一版 · 核心可用

逐句跟讀骨架

載入影片與字幕 → 句子清單 → 逐句跟讀（留白倍數）→ 單句循環 → 變速不變調 → 快捷鍵 → 進度記憶。

驗收：有字幕的影片可完整跑一次逐句跟讀流程。
第二版 · 內容打通

無字幕也能練

faster-whisper 轉寫與快取、收藏句 + 跨影片複習清單、雙語字幕、手動合併 / 拆分句子。

驗收：無字幕影片也能自動生成句子清單。
第三版 · 兒童體驗

孩子自己練

錄音對比、孩童模式全套（大按鈕 / 星星 / 每日目標 / 鎖定）、練習統計。

驗收：孩子可在孩童模式下獨立完成 10 句練習。

分期邏輯：第一版不碰 AI 與錄音，技術風險最低，卻已涵蓋跟讀最核心的體驗；後兩版在穩定骨架上逐步加功能。

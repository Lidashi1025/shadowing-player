# 影片收藏夾與啟動恢復設計

## 目標

增加兩個彼此配合的影片級功能：

- 將目前播放的 MKV／MP4 加入收藏夾，之後可從收藏夾快速打開。
- 下次啟動應用程式時，自動載入最後一次播放且仍然存在的影片，恢復原有進度，
  並保持暫停等待使用者按播放。

既有的句子收藏、跨影片複習清單、最近觀看與每部影片進度功能維持不變。

## 已有能力與設計選擇

`ProgressStore` 已使用 SQLite 的 `videos` 資料表保存每部影片的路徑、指紋、播放
位置、速度、模式、字幕來源、字幕顯示模式及最後打開時間。`MainWindow.open_video()`
已能讀取上述進度並在恢復後暫停。

本功能直接擴充 `videos` 資料表，而不另建重複保存路徑或進度的收藏表，也不把收藏
資訊分散到 `settings.json`。每部影片最多只有一筆收藏；收藏狀態和最新播放進度共用
同一筆影片記錄，避免同步問題。

## 資料模型與遷移

資料庫 schema 版本由 1 升至 2。`videos` 新增：

- `is_favorite INTEGER NOT NULL DEFAULT 0`
- `favorited_at TEXT`

並建立依 `is_favorite`、`favorited_at` 查詢的索引。從既有資料庫升級時保留所有
影片進度、句子、句子收藏與編輯狀態；既有影片預設不是影片收藏。

`ProgressStore` 增加以下職責：

- 設定或取消指定影片的收藏狀態。
- 判斷指定影片是否已收藏。
- 依收藏時間由新到舊列出收藏影片。
- 取得最後一次打開的影片候選，供啟動恢復使用。

加入收藏時必須先把目前播放器狀態保存到既有影片記錄，再設定收藏狀態。之後正常
切換影片、關閉程式或再次播放時，既有進度保存流程會持續更新同一筆記錄，因此收藏
入口永遠恢復最後觀看位置，而不是加入收藏當下的固定快照。

取消收藏只清除 `is_favorite` 與 `favorited_at`，不刪除影片記錄、播放進度或句子。
重複加入同一影片只更新收藏時間，不新增重複項目。

## 收藏夾介面

頂部「最近觀看」旁新增「收藏夾」按鈕與下拉選單。選單內容：

1. 第一項是目前影片的操作：
   - 未載入影片時顯示不可點擊的「尚未載入影片」。
   - 目前影片未收藏時顯示「收藏目前影片」。
   - 目前影片已收藏時顯示「取消收藏目前影片」。
2. 分隔線。
3. 依收藏時間由新到舊列出仍然存在的 MKV／MP4。

收藏項目顯示檔名，工具提示顯示完整路徑。點擊收藏項目沿用 `open_video()`，恢復該
影片的最新進度、速度、模式、字幕來源與字幕顯示模式，並保持暫停。

收藏檔案已移動、刪除或副檔名不受支援時，不顯示在選單中，但不自動刪除資料庫記錄，
避免外接磁碟暫時未連接時丟失收藏。沒有可顯示的收藏項目時，在分隔線下顯示不可點擊
的「收藏夾是空的」。

## 啟動恢復

視窗完成元件、播放器、控制器、訊號及快捷鍵初始化後，以 Qt 的零延遲單次排程觸發
啟動恢復，避免在 `MainWindow` 建構過程中直接執行完整的影片與字幕載入流程。

恢復流程依最後打開時間由新到舊檢查影片記錄，選擇第一個仍然存在且副檔名為 MKV
或 MP4 的檔案。找到後呼叫既有 `open_video()`；該流程會驗證影片指紋、載入字幕或
轉寫快取、恢復狀態並暫停。若最新影片已不存在，可以回退到下一部仍存在的最近影片。

若沒有有效影片，維持現有空白首頁。若自動載入時發生檔案、字幕或播放器錯誤，錯誤
不得讓應用程式啟動失敗；狀態列顯示簡短訊息，使用者仍可手動打開其他影片。

啟動恢復只在視窗初次建立時執行一次。恢復後不自動播放、不發出聲音。

## 與既有功能的關係

- 「最近觀看」仍列出最近八部有效影片，不受收藏狀態影響。
- 影片收藏與句子星號收藏是不同概念；句子收藏快捷鍵、按鈕與複習清單不改名。
- 收藏影片後播放進度仍透過 `_save_current_progress()` 保存。
- 收藏入口和啟動恢復都重用 `open_video()`，不建立第二套載入或恢復邏輯。
- 全域速度與模式設定仍保存到 `settings.json`；打開有影片進度的影片時，影片狀態
  依既有規則優先。

## 錯誤處理

- 對不存在或不受支援的路徑不執行收藏操作。
- 收藏資料庫操作失敗時保留目前播放狀態，狀態列顯示錯誤，不關閉程式。
- 已收藏檔案暫時不可用時隱藏項目但保留記錄。
- 影片內容已變更導致指紋不同時，沿用既有行為，不恢復舊進度。
- 啟動恢復失敗時不再次循環嘗試，避免錯誤對話框或轉寫工作重複出現。

## 測試與驗收

單元測試覆蓋：

- 加入收藏、取消收藏、收藏判斷與重複加入。
- 收藏依時間排序且支援上限。
- 收藏後正常保存會更新同一影片的最新進度。
- 最後打開候選依時間排序。
- schema 1 升級至 schema 2 時完整保留既有資料。

Qt 整合測試覆蓋：

- 收藏夾選單在未載入、未收藏及已收藏影片時顯示正確操作。
- 加入收藏前先保存當前播放位置，取消收藏不刪除進度。
- 收藏選單過濾不存在或不支援的檔案，點擊有效項目呼叫 `open_video()`。
- 視窗啟動後自動打開最後一部有效影片、恢復位置並保持暫停。
- 沒有有效最近影片時維持空白首頁。

完成後執行完整 pytest 測試套件、封裝自檢相關測試及 Windows 資料夾版建置檢查。

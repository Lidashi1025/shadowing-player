# 播放、转写与快捷键体验修复设计

## 范围

本轮只改善现有第一、二版能力，不增加录音、儿童模式或统计。目标是：

- 句子列表只有一个明确的正在播放标记，并显示真实可点击的收藏星。
- 转写完全在主窗口内后台进行，影片可以立即观看。
- 转写快取随便携程序文件夹迁移。
- 单击左箭头可以可靠重播本句。
- 快捷键集中、可见、可编辑，并有符合暗色界面的设置面板。
- 所有文字控件在 Windows 常见缩放比例下不裁切。

## 已确认根因

1. 句子表格使用整列选择，同时当前索引落在收藏栏。Qt 对两个选中储存格分别绘制
   焦点，因此截图出现两条蓝线。
2. 收藏栏依赖透明的原生核取框指示器。未收藏时完全透明，收藏后也只是橙色圆形，
   没有星号。
3. `repeat_current()` 在观看与影子模式只调用播放，没有先跳到当前句的播放起点。
4. 转写工作已经位于 `QThread`，但主界面先暂停影片并显示浮动 `QProgressDialog`，
   用户体验仍像被阻塞。
5. 转写快取位于 `%LOCALAPPDATA%`，不会随 `ShadowingPlayer` 文件夹迁移。
6. 快捷键提示是普通 `QMessageBox` 文本，没有分类、冲突检查或编辑能力。
7. “自动下一句”使用固定 108px 宽度，没有为字体与 DPI 内距保留空间。

## 句子列表状态

句子表格改为“文字在左、星号在右”：

- 当前播放句使用一条 3px 蓝色左边线和轻微蓝色底色。
- Qt 储存格焦点框被代理移除，不再出现双蓝线。
- `☆` 表示未收藏，`★` 表示已收藏；已收藏使用橙色。
- 点击文字跳转，点击星号只切换收藏。
- 播放位置变化只更新模型的当前播放行，不改变用于合并句子的多选状态。
- 多选行使用中性灰蓝底色，与当前播放状态区分。

## 重播行为

`SessionController.repeat_current()` 对所有模式都以当前句为入口：

- 观看与影子模式：跳到 `play_window()` 起点后连续播放。
- 逐句跟读与单句精听：沿用单句状态机，跳到起点并开始本次循环。
- 单击 `←` 调用重播；400ms 内第二次 `←` 调用上一句。
- 另提供 `Ctrl+←` 作为无时间窗口的明确“上一句”快捷键。

## 后台转写与便携快取

移除浮动进度对话框，主窗口控制列下方增加一个默认隐藏的活动条：

```text
正在生成英文字幕 42% · 已用 28 秒 · 预计剩余 39 秒       [取消]
```

打开没有英文字幕的影片时：

1. libmpv 立即打开并播放影片。
2. 现有控件、拖放、最近观看、暂停、速度和全屏保持可用。
3. 工作线程继续发出阶段与百分比讯号，主线程只更新活动条。
4. 转写完成后在当前播放位置载入句子，不重新打开影片，不跳回开头。
5. 转写取消或失败时活动条收起，影片继续可用。

主要快取目录为：

```text
<ShadowingPlayer 程序目录>\cache\transcriptions\<影片快速杂凑>.srt
```

源码开发时对应项目根目录的 `cache/transcriptions`。旧
`%LOCALAPPDATA%\ShadowingPlayer\cache` 作为只读相容来源；找到旧快取时复制到
便携目录并直接使用。便携目录无法写入时显示明确错误，不让程序崩溃。

## 转写效率

在当前电脑对实际 Odd Squad 60 秒片段的测量：

- faster-whisper small、CPU、int8、beam 5：3.584 秒，实时因子 0.060。
- 模型载入：0.887 秒。
- beam 1：2.519 秒，但输出文字从 340 字符下降到 290 字符。

beam 5 已达到约 16.7 倍实时速度，20 分钟影片约需 70–90 秒。为了避免漏词，维持
beam 5、英文固定、VAD 与逐词时间戳；不以准确度换取约一秒的模型载入优化。活动条
增加经过时间与预计剩余时间，让速度可见。

## 快捷键系统

新增集中定义的快捷键目录，注册器与设置面板读取同一份资料，避免功能隐藏或文案
不一致。F1 打开暗色快捷键设置面板。面板按“文件、播放、练习、显示”分类，每行
显示功能名称、说明与 `QKeySequenceEdit`：

| 功能 | 默认按键 |
|---|---|
| 打开视频 | Ctrl+O |
| 最近观看 | Ctrl+H |
| 播放／暂停 | Space |
| 重播本句 | Left |
| 上一句 | Ctrl+Left |
| 下一句 | Right |
| 加速／减速 | Up／Down |
| 单句循环 | L |
| 字幕模式 | M |
| 播放模式 | Tab |
| 收藏当前句 | S |
| 复习清单 | R |
| 全屏 | F |
| 快捷键面板 | F1 |

面板支持保存、恢复默认与取消。空按键允许取消绑定；重复按键会标红冲突行并禁止
保存。保存后立即重新注册快捷键并写入 `settings.json`。

## 文本与缩放

- 移除“自动下一句”的 108px 固定宽度，以 `sizeHint()` 和字体度量设定安全最小值。
- 保持单列控制栏，不增加永久高度。
- 组合框继续验证编辑区能完整容纳当前文字。
- Qt 整合测试覆盖 1024px 视窗，以及 100%、125%、150% 字体缩放下的文字宽度。

## 错误与资料保护

- 不更改 SQLite 架构，不清除播放进度、收藏或句子编辑。
- 转写活动仅属于当前影片；换片会取消旧工作，旧完成讯号不得写入新影片。
- `cache/`、模型、DLL、build、dist、影片与测试音讯不会提交 GitHub。
- GitHub 发布使用私人储存库；源代码、文档、测试与打包脚本进入版本控制。

## 验收

- 当前播放句只有一条蓝线，右侧稳定显示 `☆／★`。
- 单击 `←` 和重播按钮都跳到当前句开头。
- 转写时影片可以播放、暂停和调速，主窗口没有浮动进度对话框。
- 活动条显示百分比、经过时间、预计剩余时间和取消。
- 转写结果写入程序目录快取，第二次打开直接载入。
- 快捷键面板显示并可编辑所有绑定，冲突无法保存。
- 1024px 和常见缩放比例不裁切“自动下一句”。
- 完整回归、冻结版 smoke test 与实际快捷方式启动通过后才发布 GitHub。
